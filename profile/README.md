**basebin** is a collection of small-to-medium open-source projects focused on machine learning, inference, GPU kernels, SDKs, and developer tooling.

Most repositories are practical experiments, utilities, and building blocks that can be studied, reused, or adapted.

### Areas of focus
- GPU kernels & low-level compute
- Inference frameworks and runtimes
- Machine learning APIs and clients
- SDKs and agent tooling
- CLI utilities and build infrastructure

### Selected repositories

| Repository | Description |
|------------|-------------|
| [kernels](https://github.com/basebin/kernels) | Swift GPU kernels |
| [ml](https://github.com/basebin/ml) | Machine learning framework in C++ |
| [mlapi](https://github.com/basebin/mlapi) | Machine learning API (Python) |
| [bitinfer](https://github.com/basebin/bitinfer) | Inference framework in C++ |
| [mlxlm](https://github.com/basebin/mlxlm) | M1 / Apple Silicon inference tests |
| [xaisdk](https://github.com/basebin/xaisdk) | SDK and client libraries |
| [cli](https://github.com/basebin/cli) | Command-line utilities |
| [buildanywhere](https://github.com/basebin/buildanywhere) | Cross-platform build tooling |
