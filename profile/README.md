### Scope

- GPU compute and image tools
- AI and machine learning
- Apps and SDKs
- CLI and build tools

Each repo is small. Most can be read in under 30 minutes.

### Repos

**Compute**
- [`kernels`](https://github.com/basebin/kernels) - GPU kernels in Swift
- [`bitinfer`](https://github.com/basebin/bitinfer) - AI runner in C++
- [`thread`](https://github.com/basebin/thread) - Tile, upscale, and stitch images
- [`mlxlm`](https://github.com/basebin/mlxlm) - AI tests for Apple M1 Macs

**AI**
- [`ml`](https://github.com/basebin/ml) - Machine learning in C++
- [`mlapi`](https://github.com/basebin/mlapi) - Machine learning API in Python
- [`benchmark`](https://github.com/basebin/benchmark) - Speech tests
- [`vesper`](https://github.com/basebin/vesper) - Client for Gemini

**Dev tools**
- [`cli`](https://github.com/basebin/cli) - Command line tools
- [`buildanywhere`](https://github.com/basebin/buildanywhere) - Build on any computer
- [`dotfiles`](https://github.com/basebin/dotfiles) - Mac dev setup
- [`appsdk`](https://github.com/basebin/appsdk) - GitHub App base
- [`hautofix`](https://github.com/basebin/hautofix) - Code fix helper

**Apps**
- [`browser`](https://github.com/basebin/browser) - Browser app in Flutter
- [`tts`](https://github.com/basebin/tts) - Text to speech
- [`hub`](https://github.com/basebin/hub) - Collaboration app
- [`metal`](https://github.com/basebin/metal) - Swift tests

[All 103 repos](https://github.com/orgs/basebin/repositories).

### Start

```bash
git clone https://github.com/basebin/thread.git && cd thread
git clone https://github.com/basebin/mlapi.git && cd mlapi && pip install -e .
gh repo list basebin --limit 103 --json name,primaryLanguage,description
```

### Stack

`Python` 27, `TypeScript` 11, `Shell` 9, `C++` 7, `JavaScript` 7, `Swift` 7. Plus C, Dart, Rust and more.

- Report: open an issue for bugs or requests.
