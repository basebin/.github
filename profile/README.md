### What is basebin?

basebin is a set of small projects.

We make tools for:
- fast computer work with GPUs
- AI and machine learning
- apps and SDKs
- command line tools and build help

Each project is small. You can read one in less than 30 minutes. You can copy it and change it for your needs.

> Look around. Copy what helps. Build something new.

### What you can find here

**1. Speed tools**

Low level work. GPUs. Image tools.

- [`kernels`](https://github.com/basebin/kernels) - GPU kernels in Swift
- [`bitinfer`](https://github.com/basebin/bitinfer) - simple AI runner in C++
- [`thread`](https://github.com/basebin/thread) - cut images in tiles, make them big, join them back
- [`mlxlm`](https://github.com/basebin/mlxlm) - AI tests for Apple M1 Macs

**2. AI tools**

Learn and test AI.

- [`ml`](https://github.com/basebin/ml) - machine learning in C++
- [`mlapi`](https://github.com/basebin/mlapi) - machine learning API in Python
- [`benchmark`](https://github.com/basebin/benchmark) - test for speech tools
- [`vesper`](https://github.com/basebin/vesper) - simple client for Gemini

**3. Tools for builders**

Help for daily work.

- [`cli`](https://github.com/basebin/cli) - command line tools
- [`buildanywhere`](https://github.com/basebin/buildanywhere) - build on any computer
- [`dotfiles`](https://github.com/basebin/dotfiles) - setup for Mac dev
- [`appsdk`](https://github.com/basebin/appsdk) - help to make GitHub Apps
- [`hautofix`](https://github.com/basebin/hautofix) - help to fix code

**4. Small apps and tests**

Simple apps to learn from.

- [`browser`](https://github.com/basebin/browser) - browser app in Flutter
- [`tts`](https://github.com/basebin/tts) - text to speech
- [`hub`](https://github.com/basebin/hub) - app to work together
- [`metal`](https://github.com/basebin/metal) - Swift tests

Want more? [See all 103 repos here](https://github.com/orgs/basebin/repositories).

### How to start

Do this in 3 steps.

```bash
# 1. Pick one. For example the image tool:
git clone https://github.com/basebin/thread.git && cd thread

# 2. Or pick the Python API:
git clone https://github.com/basebin/mlapi.git && cd mlapi && pip install -e .

# 3. See all by language:
gh repo list basebin --limit 103 --json name,primaryLanguage,description
```

That is it. Read it. Run it. Change it.
