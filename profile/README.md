## Hi there

basebin is a collection of small open source projects for machine learning, inference, GPU kernels, SDKs, and developer tooling.

Important repositories for compute and inference
- [kernels](https://github.com/basebin/kernels) - Swift GPU kernels.
- [bitinfer](https://github.com/basebin/bitinfer) - Inference framework.
- [ml](https://github.com/basebin/ml) - Machine learning framework.
- [mlapi](https://github.com/basebin/mlapi) - Machine learning API.
- [mlxlm](https://github.com/basebin/mlxlm) - M1 inference tests.
- [thread](https://github.com/basebin/thread) - Tiled image pipeline.
- [benchmark](https://github.com/basebin/benchmark) - Speech benchmark.
- [vesper](https://github.com/basebin/vesper) - Gemini client.

Important repositories for SDKs and tooling
- [xaisdk](https://github.com/basebin/xaisdk) - xAI API SDK.
- [cli](https://github.com/basebin/cli) - CLI tools.
- [buildanywhere](https://github.com/basebin/buildanywhere) - CI pipeline.
- [appsdk](https://github.com/basebin/appsdk) - GitHub App framework.
- [dotfiles](https://github.com/basebin/dotfiles) - Dotfiles toolkit.
- [hautofix](https://github.com/basebin/hautofix) - Code repair tool.
- [pathutils](https://github.com/basebin/pathutils) - Path utilities.

Other repositories for apps and experiments
- [browser](https://github.com/basebin/browser) - Flutter browser app.
- [tts](https://github.com/basebin/tts) - Text to speech.
- [hub](https://github.com/basebin/hub) - Collaboration app.
- [metal](https://github.com/basebin/metal) - Swift package notes.
- [barepi](https://github.com/basebin/barepi) - Raspberry Pi notes.
- [lilt](https://github.com/basebin/lilt) - Android messenger.
- [sandbox](https://github.com/basebin/sandbox) - Sandbox repo.
